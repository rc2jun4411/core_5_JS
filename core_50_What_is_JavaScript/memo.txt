A1:
  HTML側の onclick 属性を削除し、JavaScript側で
対象の要素を取得して addEventListener を使うのが
標準的かつ最も推奨される方法です。
HTML側: 
  属性を削除し、要素を特定するための id や class など
  を付与します。  
  <button id="create-btn">Click me!</button>
index.js側:
  要素を取得してイベントリスナーを設定します。
  const button = document.querySelector('#create-btn');
  button.addEventListener('click', createParagraph);  
Q1 well done!, closed.

A2:
はい、完全に共用（再利用）できます。
JavaScriptで一度定義した関数は、複数の要素や
イベントリスナーから呼び出すことが可能です。
共用する例:
// 関数の定義（1つだけ作成）
function updateName() {
  const name = prompt('名前を入力してください');
  // 名前を変更する処理...
}

// 複数のボタン取得
const button1 = document.querySelector('#btn-1');
const button2 = document.querySelector('#btn-2');

// それぞれのボタンをクリックした際におなじ関数を実行
button1.addEventListener('click', updateName);
button2.addEventListener('click', updateName);
