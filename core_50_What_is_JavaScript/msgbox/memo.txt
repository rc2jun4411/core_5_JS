AI による概要:
  JavaScriptでは、メッセージボックス（ポップアップダイアログ）を
表示するために alert() 関数を使います。

アラートボックス:
  アラートボックスの基本メッセージを表示するには、コードに 
alert("表示したい文字"); と書きます。
javascript:
alert("こんにちは！");
ユーザーが「OK」ボタンを押すまで、次の動作は止まります。
その他のダイアログ用途に合わせて、別の種類のボックスも使えます。

確認ボックス (confirm): 
 「OK」と「キャンセル」を選べます。
javascript:
const res = confirm("続けますか？");

入力ボックス (prompt):
  文字を入力できます。
javascript:
const name = com = prompt("お名前は？");  <= error ????

詳しい仕様やブラウザーごとの動きは、MDN Web Docsのwindow.alert解説を確認してください。
